# WAX (Worldwide Asset eXchange)

> WAX is a purpose-built, carbon-neutral layer-1 blockchain (an Antelope/EOSIO fork) for NFTs, gaming, and e-commerce. Developers interact with it through the public Antelope Chain API (/v1/chain/*), the Hyperion History API, and the WAX Cloud Wallet via the official @waxio JavaScript SDKs. Read RPC is unauthenticated; state changes are authorized by client-side secp256k1 transaction signatures.

## APIs
- Chain API: Antelope RPC at /v1/chain/* (e.g. get_info, get_account, get_table_rows, push_transaction). Public read; POST JSON. Example public endpoint: https://wax.greymass.com
- History API: Hyperion at /v1/history/* and /v2/* (actions, transactions, deltas).
